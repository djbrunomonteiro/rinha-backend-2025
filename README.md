# Rinha de Backend 2025 - NestJS

Este repositório contém a minha participação na **Rinha de Backend 2025**, implementada com o framework **NestJS**.

---

## Como rodar

Certifique-se de ter o **Docker** e o **Docker Compose** instalados.

```bash
git clone https://github.com/djbrunomonteiro/rinha-backend-2025
cd rinha-backend-2025
docker compose up --build
```

## Sobre a ideia

Optei por utilizar uma tecnologia que venho estudando atualmente. Sou desenvolvedor frontend com foco em Angular, e estou conciliando esse desafio com a gravidez do meu primeiro filho.

Tentei explorar as novas funcionalidades do Node.js, como multithreading (via worker_threads) em conjunto com RxJS operators para controle de fluxo assíncrono.

Sei que, em cenários de alta demanda, o Node pode apresentar algumas limitações de performance em comparação a outras linguagens mais voltadas ao backend, mas o objetivo aqui era fazer funcionar bem dentro da proposta, e ver até onde dá para chegar!
